# Sprache bei beuwy — die eine Regel

> **Stand:** Entwurf zur Abnahme. Noch NICHT auf der ganzen Seite ausgerollt.
> Erst Muster abnehmen, dann rollen wir es überall aus.

## Die Regel

**Schreib so, dass ein 14-Jähriger es sofort versteht.**

Wenn ein Wort erklärt werden muss, ist es das falsche Wort. Kein Marketing-Sprech,
kein Agentur-Deutsch, kein Englisch-Mischmasch. Klar. Deutsch. Auf den Punkt.

**Der Test:** Lies den Satz laut vor. Würdest du das einem Kumpel am Tisch genau so
sagen? Wenn nein → umschreiben.

---

## Verbotene Wörter (unsere eigenen „No-Go-Wörter")

Ironie: beuwy hat Kunden immer „Forbidden Phrases" verkauft. Jetzt gelten sie für
uns selbst. Links steht, was raus muss. Rechts, was ein Mensch sagen würde.

| ❌ Raus | ✅ Stattdessen |
|---|---|
| Agent-Layer | „damit ChatGPT, Google & Co. deine Firma kennen und nennen" |
| maschinenlesbar / agentenlesbar | „Computer und KI können es lesen" |
| indizierbar | „wird bei Google gefunden" |
| kategorie-definierend / „die Kategorie setzen / besitzen" | „der Erste, an den die Leute in deiner Branche denken" |
| Operator / Operator-led | „ich mach das selbst" / „du redest direkt mit mir, nicht mit einem Manager" |
| Compound-Standby / Compounding | „ich bleib nach dem Launch noch [X] Wochen für dich da" |
| Cohort-Receipts / Cohort | raus — oder „echte Zahlen von echten Projekten" |
| Cluster-Brief | raus (internes Werkzeug, gehört nicht auf die Kundenseite) |
| DESIGN.md · Tokens · Forbidden Phrases | „ein klares Marken-Handbuch: Farben, Schriften, wie deine Marke spricht" |
| Discovery-Theater / Discovery-Sprint | „wochenlange Workshops, die am Ende nur Folien bringen" |
| Track-Record | „was ich schon gebaut hab" |
| „von 0 zur Kategorie" | „von unbekannt zu bekannt" |
| Premium-Design, das die Branche verwirrt | raus — einfach zeigen, nicht behaupten |
| Festpreis pro Slot | „ein fester Preis, den du vorher kennst" |
| ICP / High-ACV / DTC / B2B | die Zielgruppe in normalen Worten nennen |

> Anglizismen, die jeder kennt, sind ok: „Website", „Logo", „Brand", „Online", „Team".
> Aber keine ganzen englischen Sätze/Slogans — die versteht über die Hälfte der
> Deutschen nicht vollständig (Endmark/YouGov).

## Was beuwy wirklich macht (in einem Satz, plain)

> *„Ich baue kleinen Firmen und Gründern in kurzer Zeit eine richtig gute Marke
> und Website — Logo, Farben, Texte, fertig zum Online-gehen. Zum festen Preis."*

Alles, was wir schreiben, muss zu diesem Satz passen. Wenn ein Text klüger klingen
will als dieser Satz, ist er falsch.

---

## Was als Nächstes passiert (Reihenfolge)

1. Echte Marktdaten abwarten (Preis, was Kunden wirklich wollen, ob „KI-Sichtbarkeit"
   überhaupt ein echtes Thema für zahlende Kunden ist).
2. Positionierung + Preis auf Basis der Daten festlegen — nicht auf Basis von Annahmen.
3. Diese Sprach-Regel auf die ganze Seite ausrollen (Home, /system, /sichtbar,
   /method, /manifesto, /work, /go/* — überall).
